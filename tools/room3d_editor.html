Retoques de habitación

Ajusta la geometría sobre el fondo original. El contorno cian muestra el grupo seleccionado; las líneas no representan oclusión ni texturas finales.






X/Y/Z son unidades del juego. Y negativo sube. El giro usa grados. El pivote inicial es el centro del grupo; puedes fijar otro.

Cómo generar el resultado con texturas

Guarda el JSON y aplica las correcciones con tools/room3d_retouch.py --room CARPETA_ORIGINAL --edits CORRECCIONES.json --out CARPETA_NUEVA.

Este editor funciona sin conexión. No cambia archivos del juego ni colisiones. Las superficies ausentes requieren geometría adicional.
